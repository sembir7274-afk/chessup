# Backdrop media

Drop your Higgsfield-generated media here:

| File             | Role                                                        |
| ---------------- | ----------------------------------------------------------- |
| `background.mp4` | Seamless looping video backdrop (preferred)                  |
| `background.jpg` | Still frame — used as the video poster, and as the fallback  |

Neither file is committed (see `.gitignore`), and neither is required: with
both absent the deck renders a procedural neon-gradient backdrop instead.

See the "Higgsfield backdrop" section of the project README for generation
prompts, encoding settings and readability tuning.
